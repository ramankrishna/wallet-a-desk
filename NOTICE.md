# Notices

Wallet A Desk uses FriendSDK v0.1.2 (`@rarefriends/friendsdk`), Apache-2.0.

The Friend on the desk is that account's canonical Rare Friends Generations artwork. The game reads it at runtime from the pinned Generations registry and draws the original pixels. It does not recolor, crop, or mirror them. No sprite files are stored in this repository.

Sounds are the FriendSDK sound kit. The desk's layout, type, and colors are original to this project. There is no other third-party artwork.
